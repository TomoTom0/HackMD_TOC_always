# Privacy Policy - HackMD TOC always

**Last updated: 2026-02-21**

## Data Collection

This extension collects and processes the following data on HackMD (hackmd.io):

| Data Type | Description | Purpose |
|-----------|-------------|---------|
| Document headings | Text content of h1-h6 elements | Generate Table of Contents |
| User interactions | Click and keypress events | Control TOC display and navigation |
| Page URL | Current HackMD URL | Detect edit/view mode |
| User settings | TOC visibility, width, opacity | Save preferences |

## Data Storage

- **Chrome Sync Storage**: User preferences (visibility, width, opacity settings)
- **Local Processing**: Document headings and interactions are processed locally in real-time and not stored

## Third-Party Sharing

This extension does **not** share, sell, or transmit any user data to external servers or third parties.

## Data Retention

- User settings: Retained until the extension is uninstalled or settings are cleared
- Document content: Not stored; processed only in real-time

## Permissions

- `storage`: Save user preferences locally
- Content script on `https://hackmd.io/*`: Access page content for TOC generation

## Contact

For questions about this privacy policy, please open an issue on the [GitHub repository](https://github.com/TomoTom0/HackMD_TOC_always).
